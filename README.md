# Школьная неделя

Конструктор недельного расписания ребёнка: уроки, кружки, дорога, домашка, секции. Плакат можно напечатать на A3.

- Класс 4.3 — https://kaaandr.github.io/raspisanie/4/
- Класс 9.4 — https://kaaandr.github.io/raspisanie/9/

Расписание хранится только в браузере того, кто его составляет. Для переноса на другое устройство — «Сохранить в файл» и «Открыть файл».
